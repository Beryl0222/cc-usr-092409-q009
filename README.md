# 医者荣誉贡献档案

团队贡献归属、患者同意与公开叙事校正服务的领域实现。所有状态都由不可变事件归约得到，更正只能追加后继记录。

## 业务规则

- **贡献声明**绑定时间（`work_period`）、职责（`role`/`duty`）、证据摘要与共同参与者；当事人确认（在线或离线）后，**独立审核人**才能裁定归属。
- **自动聚合只产出建议**（`ATTRIBUTION_SUGGESTED`，标记 advisory），永远不构成结论；对外发布必须存在独立裁定或其后的更正。
- 同一成果允许多人按不同角色获得说明，`achievement_count` 恒为 1，不按人头重复计算；同一人不能在同一成果中重复占行。
- **证明/离线确认按指纹归并**：同指纹同内容只追加来源（`DUPLICATE_MERGED`）；同指纹不同内容挂起等待复核。裁定之后到达的冲突证明是“迟到证明”，当前结论保持有效，复核期间暂缓新发布。
- **患者同意**按“用途 × 渠道 × 字段 × 有效期”逐项最小披露；撤回（可部分）只阻止新发布，并为已发布版本追加撤回处置，历史版本不改写。发布版本绑定当时背书的 scope，旧版本不会被同渠道的新授权“复活”。
- **异议成立**生成归属更正；历史提名、投票、已发布版本保持原样，后续材料与公众视图采用当前有效结论（更正优先于裁定）。
- **通知队列持久化**：撤回通知与异议期限到期提醒在进程重启后继续投递，按业务键幂等去重。
- **内部查询**还原团队贡献、同意链、校正理由与不可变历史；**公众查询**只返回当前获准的故事摘要。

## 目录

- `contracts/domain.schema.json`：领域事件信封与全部事件/聚合类型。
- `src/events.js`、`src/validator.js`：事件名称、聚合类型、信封构造与校验。
- `src/fingerprint.js`：规范化 JSON 与 SHA-256 内容指纹。
- `src/domain/`：纯函数聚合（review / consent / story / honor），无 I/O，可单测。
- `src/store/`：JSONL 事件存储（乐观并发 + 进程内串行锁）与持久通知队列。
- `src/archiveService.js`：应用服务，命令在单把锁内完成“读最新历史 → 裁定 → 追加事件”。
- `src/readModel.js`：内部视图与公众摘要投影。
- `data/sample.json`：贡献声明事件样例。
- `tests/`：契约测试与场景测试（共同贡献、迟到证明、部分撤回、并发裁定、重启恢复等）。

## 本地检查

```bash
npm test     # node --test，全部场景测试
npm run build # 对 src 下所有文件做语法检查
```

命令在单个 Linux 容器内执行，不需要外部服务；事件与通知写入临时目录（测试）或指定的归档根目录。
